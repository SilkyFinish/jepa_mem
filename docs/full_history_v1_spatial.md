# 可选 Full-History v1：历史空间压缩

在 `full-history-v0` 分支内通过 `--policy-arch full_history --history-model-version v1` 显式选择。默认版本仍为 v0，原始 legacy 默认入口也保持不变。v1 是 From Scratch 的空间压缩消融：冻结 Encoder/T5，联合训练 Predictor 与 Action Expert。

## 压缩定义

每个历史观测块先保留三相机独立的原始 `14×14` Encoder 特征，再在进入 Predictor 的线性投影与全部 Transformer 层之前，对每个相机分别作无参数 `2×2` 平均池化，得到 `7×7`。每块历史从 588 tokens 降至 147，最长 81 块从 47,628 降至 11,907。完整历史时间轴、每块状态条件、相机顺序、语言、32 步动作、未来四组查询/监督的 2,352 tokens 均保持不变。压缩是有损模型变更，不能推定成功率不变或总显存按四倍减少。

历史 RoPE 空间坐标使用原网格中池化单元的中心，即 `0.5, 2.5, …, 12.5`；仍沿用原 `14×14` 网格到 Encoder canonical grid 的插值尺度。时间坐标、block ID 和因果可见性保持原定义。每个观测块从首次进入 Predictor 就采用相同压缩规则，在线增量缓存与训练全量重算一致；没有随历史年龄变化的重压缩，也没有跨时间/相机合并或历史截断。

## 入口与兼容性

训练命令仅需在已有 full-history 命令中增加以下参数：

```bash
--history-model-version v1
```

`--history-model-version v0` 或省略此项使用原版本。v1 的固定池化因子、池化方法、空间坐标规则写入 `memory_schema`，顶层 `model_version=v1`。检查点加载器按 metadata 自动重建；v0/v1 的完整策略互相恢复会在修改参数前拒绝，即使权重张量形状相同。显式 `--predictor-init` 仍是单独的 Predictor 迁移入口，不等于完整续训。当前 v0 分支的训练检查点只保存权重和进度，不含 AdamW moments。

冻结特征缓存仍存原始 588-token 观测和全分辨率未来目标，数据与线上 RGB 采样协议仍为 `rmbench_history_v0` / `rmbench_memory_v0`。v1 不把压缩后的特征或可训练 KV 写回冻结缓存。缓存的编码源码校验保持严格，本次改动后必须使用新生成的 manifest，旧缓存和旧实验不覆盖。

后续同分支已接入可选的完整训练状态保存与恢复；上文“只保存权重和进度”描述本次吞吐实验时的状态。分阶段正式训练应开启 `--save-training-state` 并恢复 `resume_state.pt`，详见[串行训练评测](full_history_staged_training.md)。

## 本机诊断

`scripts/benchmark_history_training.py` 通过实际 Trainer、DDP、数据集、优化器和保存流程测量训练吞吐。正常训练参数之外可传 `--benchmark-stress-updates 2`，把第一轮前两次更新的全部样本替换为数据集中最长的完整历史，用于测量 AdamW 状态初始化后的峰值显存；其余样本使用真实数据。每 rank 的 `rank*_timing.json` 记录更新耗时、真实/填充历史长度、loss、峰值显存和参数同步检查。只有 launcher 正常退出、保存成功才视为运行通过。带压力样本的诊断不能描述为无重复的完整 epoch。

正式模型的吞吐测试不是闭环成功率实验；压缩有效性仍需与 v0 使用同等训练预算和评测种子比较。100 epoch 时间估算应使用全量 50 条轨迹的代表性更新，单独记录缓存构建、模型加载和保存耗时。

## 2026-10-22 双 RTX 5090 实测

实验位于 HDD 的 `runs/full_history_v1_spatial_20261022/`，本机路径由忽略的 `configs/memory_v1.local.env` 中 `V1_RUN` 指定。基于 `full-history-v0` 的 `e44b530a` 加本次未提交修改，没有新建分支。全量 50 条 `put_back_block` 演示已生成新的 FP32 冻结特征缓存（17.85 GiB），本次读取各条轨迹自己的真实特征。Encoder/T5 冻结；Predictor 为 24 层、宽度 1024，Action Expert 为 24 层、宽度 512，使用 BF16、segmented attention、24 层 activation checkpointing，两个 DataLoader workers/rank。

所有配置保持全局 batch=16。两个短测各做 12 次真实 AdamW 更新，前两次使用最长 81 块完整历史，后十次读取正常样本；随后从头启动无压力样本替换的完整 epoch 测速。表中更新耗时取两个 rank 的较慢值，显存为 PyTorch peak allocated（不包括驱动、桌面及 allocator 保留但未使用的空间）。

| 测试 | 每卡 batch / 累积次数 | 正常更新平均耗时 | 最长历史第二次更新 | 每卡最高分配显存 |
| --- | --- | --- | --- | --- |
| 12 步短测 | 1 / 8 | 7.75 s | 12.65 s | 17.77 GiB |
| 12 步短测 | 2 / 4 | 7.62 s | 15.39 s | 23.30 GiB |
| full50 完整 epoch，63 步 | 2 / 4 | 8.02 s | 正常采样，无替换 | 23.30 GiB |

两种 batch 的正常吞吐接近，选用短测稍快的 batch=2 完成整轮；这不能视为 batch=2 稳定显著优于 batch=1。完整 epoch 更新总耗时 505.12 秒（8 分 25 秒），包含最后保存和训练结束清理的 Trainer 耗时为 528.02 秒，含模型加载及进程退出的 launcher 耗时为 547.18 秒。最后 2.3 GiB 权重写入约 1.54 秒。最长历史压力测试的最高 reserved 显存为 23.46 GiB。三个 launcher 均退出 0，两个 rank 的全部参数和最终梯度有限，抽样参数逐值同步，Encoder 保持冻结，最后检查点均保存成功。

数据集共有 1,013 个合法决策样本；当前完整梯度累积批次规则每 epoch 使用 1,008 个样本、63 次更新，其余 5 个尾部样本本轮不更新，下一轮重新打乱。因此 **100 epoch = 6,300 次更新**。按完整 epoch 实测推算为 **14.03 小时**，加 25% 波动余量为 **17.54 小时**，建议预留 **16–18 小时**。估算依赖相同双卡、已构建缓存、模型、全局 batch 与精度，缓存构建、rollout 和训练中断不计入。正式 100 epoch 训练尚未启动。

此前 v0 双卡测得约 29.52 s/update、100 epoch 约 51.66 小时；本次 v1 相比该参考吞吐约提高 3.68 倍。此前使用 episode14 的代理特征配合 full50 历史长度分布，本次使用真实 full50，所以该比较是容量规划参考，不能写成严格控制变量的消融结果。

100 项 CPU 回归测试与源码环境检查通过，覆盖 v0 兼容、v1 池化与位置、因果隔离、稠密/分段 attention 梯度、保存版本保护及增量缓存。原始日志、逐 rank 计时、配置和检查点保留在本次实验目录；`summary.json`、`source.patch` 和 `source_snapshot/` 记录最终结果与源码。`formal_100epochs_command.json` 保存正式入口的参考命令（6,300 步、每 630 步保存），只生成命令，不启动训练。

63 步检查点已通过严格重建与真实 RGB 推理检查。BF16 的 1/5 块检查验证每层 KV、未来预测与动作的增量/重算一致性，以及 WebSocket 健康检查、有限 `32×14` 动作、逐值一致的重试、容量错误、请求冲突和会话释放。另用真实 RGB 对完整 81 块（11,907 tokens）比较分批增量写入与一次完整重算，采用相同初始动作噪声：历史 KV 最大差异 0.03125，未来预测最大差异 0.0625，归一化动作最大差异 0.001953；均通过 BF16 `atol=rtol=0.06` 检查。单会话实际 KV 约 1.09 GiB，检查中显式设置 `max_history_blocks=81`、KV 分配/暂存预算 4 GiB，同时保留两条路径时显存峰值 7.79 GiB。服务默认五块上限未被隐式改大。

最长历史首次检查因测试脚本将两种不同 cache revision 的随机动作直接比较而失败；服务随机种子包含 revision，这不构成相同噪声下的模型对比。修正诊断脚本以显式共享初始噪声后复查通过，模型代码和数值容差未改动；首次脚本与失败报告作为 `*_attempt1*` 保留。上述检查只证明训练/保存/推理链路与数值一致性，未运行模拟器 rollout，未验证压缩后的任务成功率。
