# A100 适配分支本机验证（2026-10-22）

分支 `full-history-a1008` 从 `e44b530`（`full-history-v0`）建立。本次没有启动正式 100 epoch 训练，没有连接远端 A100 主机；目的是让共享存储部署、完整续训和串行评测入口可审阅、可验证。原分支没有修改。

## 本机实测

| 检查 | 结果 |
| --- | --- |
| 完整 policy 环境回归 | 96 项通过，包括完整续训与原在线缓存 guard 回归 |
| 无训练依赖的 CI 路径 | 27 项检查结束，无失败，9 个 ML 模块按依赖条件跳过 |
| 安装依赖 | 本地 `pip check` 无冲突；新约束 `pip install --dry-run` 成功；没有重装本机环境 |
| 入口配置 | 真实 `node.sh --plan` 得到八卡 × batch1 × accumulation2、63 updates/epoch、6,300 updates |
| CPU 完整续训 | 中断后跨 epoch 恢复；权重、AdamW moments、schedule、消费样本序列逐位/逐项一致 |
| 双 RTX 5090 BF16 续训 | 独立 torchrun 进程：连续 5 updates 对比 step1 中断并重启到 step5；两 rank 的样本序列、权重、AdamW 和 schedule 完全一致，权重最大误差 0 |
| 正式模型最长历史训练 | 24 层 Predictor/Action Expert，完整 81 块，双卡 batch1 × accumulation8，全局16；两次 AdamW 更新和 launcher 退出通过 |
| 正式模型 checkpoint | 602,120,590 个 trainable state 元素，1,211 个 optimizer parameter states，全部有限；完整状态 7,226,919,078 bytes，轻量权重 2,408,940,435 bytes |
| 真实 RGB + websocket | BF16，incremental/recompute 对比、32×14 有限动作、精确请求重试、容量拒绝、关闭/断线清理均通过 |
| 新串行评测函数 | native expert 筛选种子100000；新 checkpoint 实际执行1次32控制步 smoke，2次动作查询，结果文件 complete=true、error=null；服务和客户端均退出 |

最长历史训练使用已验证的真实 episode14 冻结特征，重复最长样本测容量；不是全部50轨迹训练，也不是精度实验。两次 loss 为 2.6816、2.0304；第二步约63秒。rank0 峰值 allocated 27.786 GiB、reserved 28.637 GiB；包含模型加载、两次更新、权重与完整状态保存的 probe 共221.69秒，其中机械盘保存约81秒。该时间不能外推为 A100 全量训练吞吐。

双卡验证使用本机已有的 `NCCL_SOCKET_IFNAME=lo`、`NCCL_IB_DISABLE=1`，以及 `PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True`。这些 NCCL 限制没有写入 A100 默认配置。正式节点会记录实际 GPU/驱动/拓扑和使用者提供的 NCCL 设置，并重新测试 all-reduce。

短仿真中任务未成功（0/1），但仅执行32步、模型只做了两次最长样本更新；该记录只验证连接与执行流程，不能解读为正式任务成功率。远端正式评测使用原生500步限制和20次试验，完整历史容量126块，预算包含扩容时旧/新KV同时存活。

本次回归发现原分支 `append_history` 缺失 eval 模式和连续 block ID 的入口保护；在新分支补齐，未改变正常训练/推理 attention 的计算定义。

## 证据与剩余边界

本机全部实验文件位于用户选定 HDD 的 `VJEPA-Policy/runs/a1008_adaptation_20261022/`，不提交到 Git。关键证据：`cpu_tests_final.log`、`source_tests.log`、`install_dry_run.log`、`node_plan.json`、`ddp_resume_final/result.json`、`full_model/train/stress.json`、`full_model/checkpoint_integrity.json`、`full_model/online/result.json`、`pipeline_smoke/attempt/smoke_rollout/results.json`。保留了首轮失败日志；续训测试最初误计 DataLoader 提前读取但未消费的样本，已改为在 model forward 记录实际消费顺序。

远端尚未实测：新 conda 环境的完整安装、官方大文件实际下载、全50视觉缓存构建、八卡A100/NCCL、共享盘吞吐、远端现有仿真环境的渲染/专家/回放、新模型完整500步 rollout。对应检查已进入 `host_setup.sh` 和 `node.sh`，不以本机结果替代。正式训练前须让节点入口的所有预检成功；失败时保留 attempt 日志并返回非零状态。
