# A100 dense full-resolution upgrade: validation (2026-10-24)

Source integration: A100/BERT branch `ef6978b` plus current training branch `d5f442a`. The new `v2_full_bert` model contract retains 14x14 tokens per view (588 history tokens per observation), 2352 future tokens, the full temporal prefix and frozen 128x768 BERT features. Generic v0/T5 defaults and existing v0/v1/v2 checkpoint contracts are preserved.

Local validation uses CPU execution with CUDA hidden. Core package versions are Python 3.10, PyTorch 2.7.1+cu128, NumPy 1.26.4, h5py 3.16.0, timm 1.0.30, Accelerate 1.15.0 and Transformers 4.51.3. Existing read-only copies of the same PyTorch/NumPy/h5py releases were preloaded to avoid repeated NTFS dependency reads during another active training job; remaining dependencies came from the policy environment. Generated caches, temporary fixtures and logs stayed on HDD. Experiment tracking was disabled during CPU validation.

- Memory/model suite: 111 tests, 108 passed and three CUDA-only tests skipped. Coverage includes BERT contract/load rejection, dense/tail sampling, full-resolution frozen-cache and packed-reader identity, new checkpoint/session negotiation, shared/compact BERT loss and every parameter gradient for same/mixed episodes, and uninterrupted versus full-state continuation across an epoch boundary. Continued weights, AdamW moments, scheduler and sample order matched exactly in the reduced CPU model.
- Launcher/assets suite: 36 passed, including actual shell `--plan`, old local v0/400-epoch settings upgraded by `--dense-full`, unchanged machine config, standalone packing/warming order, early run-plan rejection and partial-pack storage budgeting.
- Eight-rank sampling: two passed. Actual Accelerate `BatchSamplerShard` simulation covered sparse/dense datasets and batch one/two, preserved global batch 16, consumed 17552 unique anchors per dense epoch and reconstructed every rank's remaining stream from the consumed cursor.

The A100 entry performs real eight-GPU NCCL, compiled FlexAttention FP32/BF16 output/gradient comparisons (including 32/64-wide heads, gaps and empty rows), cache identity checks, then three production-model AdamW updates covering longest adjacent histories and mixed episodes. These checks have not been executed on the remote A100 node in this session. No A100 throughput, completion ETA or simulator success claim follows from CPU tests. The existing full-size local GPU job was not changed.

Use `bash scripts/a1008/node.sh configs/a1008.local.env --dense-full --train-only` after pulling the branch. The preset preserves machine paths/BERT assets and selects a fresh dense full-grid 25-epoch experiment: 1097 updates/epoch, 27425 total updates, eight GPUs x batch two x accumulation one. Initial dense cache preparation and optional packing are separate from training time; old v0 optimizer state is not automatically migrated. See [deployment details](a1008_shared_training.md).
